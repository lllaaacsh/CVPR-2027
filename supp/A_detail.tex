\subsection{Architecture and training}
\label{app:supp_formulation}

\paragraph{Router architecture and gradient saliency.}
    Both mimic-video~\cite{pai2025mimicvideo} and DiT4DiT~\cite{ma2026dit4dit} share the identical router architecture, parameter count, and placement after video block 2.
    At block 2, the router receives 2048-d future tokens and the 1024-d T5 instruction embeddings that condition the video backbone.
    A linear layer projects each future token from 2048-d to 1024-d, followed by rotary positional encoding.
    A single 8-head cross-attention layer lets every future token attend to the instruction tokens with padding masked.
    The cross-attention output is added residually to the projected token, and a two-layer MLP (1024-128-1 with GELU activation) followed by a sigmoid outputs $s_{t,p} \in [0, 1]$.
    In total, the router contains 6.4M trainable parameters (2.1M linear projection, 4.2M cross-attention, and 0.13M MLP), compared with 2B parameters in the frozen mimic-video DiT.
    Counting two operations per multiply-accumulate, scoring all 16,800 future tokens on mimic-video requires 0.18 TFLOPs, corresponding to 0.2\% of a full-context query (98.0 TFLOPs) and 0.4\% of a 20\%-budget query (42.7 TFLOPs).

% \suppdraft{On DiT4DiT, the future-token and instruction inputs are 2,048- and 1,024-dimensional, respectively.
% The router uses 1,024-dimensional cross-attention with eight heads and an MLP with widths 1,024--128--1, for 6,427,905 trainable parameters.
% The input dimensions, parameter count and insertion point after the second video transformer block are shared by both configurations.}
    Selecting the top-$F$ spatial groups at full resolution is a discrete operation whose piecewise-constant ranking yields zero gradient with respect to $S_g$.
    To enable gradient supervision without altering forward activations, every tube constructed from group $g$ (four tubes if kept at full resolution, or one merged tube otherwise) is scaled by a multiplicative straight-through estimator (STE)~\cite{bengio2013estimating}:
    \begin{equation}
        \gamma_g = 1 + S_g - \operatorname{sg}(S_g),
        \label{eq:supp_ste}
    \end{equation}
    where $\operatorname{sg}(\cdot)$ denotes the stop-gradient operator.
    In the forward pass, $\gamma_g = 1$, ensuring identical computation between training and deployment; in the backward pass, $\partial \gamma_g / \partial S_g = 1$.
    Writing $\tilde{z}_i = \gamma_{g(i)} z_i$ for each token $i$ belonging to group $g(i)$, the chain rule yields
    \begin{equation}
        \frac{\partial \mathcal{L}_{\text{task}}}{\partial S_g} = \sum_{i : g(i) = g} \left\langle \frac{\partial \mathcal{L}_{\text{task}}}{\partial \tilde{z}_i},\, z_i \right\rangle,
        \label{eq:supp_chain}
    \end{equation}
    which measures the first-order sensitivity of the task loss to scaling up group $g$'s representation.
    Equation~(3) of the main paper retains the non-negative descent component, $r_g = \max(0, -\partial \mathcal{L}_{\text{task}} / \partial S_g)$, assigning a high saliency when emphasizing group $g$ reduces $\mathcal{L}_{\text{task}}$.
    Through \cref{eq:supp_ste}, the router receives both direct task gradients $\partial \mathcal{L}_{\text{task}} / \partial S_g$ and stabilized pseudo-label supervision described below, without requiring a full-context probe at test time.


\paragraph{Router objective and target smoothing.}
    For each sample $i$ at training step $n$, we compute the per-sample gradient saliency:
    \begin{equation}
        r_g^{(i,n)} = \max\!\left(0,\, -\frac{\partial \mathcal{L}_{\text{task}}^{(i)}}{\partial S_g^{(i)}}\right).
        \label{eq:supp_saliency}
    \end{equation}
    To reduce gradient variance across stochastic flow-matching steps, we track an exponential moving average (EMA) of the batch-mean saliency $\bar{r}_g^{(n)}$ with momentum $\mu = 0.9$:
    \begin{equation}
        m_g^{(n)} = \mu m_g^{(n-1)} + (1 - \mu)\bar{r}_g^{(n)}.
        \label{eq:supp_ema}
    \end{equation}
    Each sample's smoothed saliency blends this running group statistic with its instantaneous sample gradient:
    \begin{equation}
        \tilde{r}_g^{(i,n)} = \mu m_g^{(n)} + (1 - \mu) r_g^{(i,n)},
        \label{eq:supp_smooth}
    \end{equation}
    from which we construct per-sample binary pseudo-labels by marking the top-$F$ groups:
    \begin{equation}
        y_g^{(i)} = \mathbb{I}\!\big[g \in \operatorname{Top-}F\big(\tilde{r}^{(i,n)}\big)\big].
        \label{eq:supp_pseudolabel}
    \end{equation}
    If a sample yields zero positive saliency across all groups, we substitute its detached current scores $S_g^{(i)}$ prior to \cref{eq:supp_smooth} to avoid degenerate all-zero targets.
    Both the EMA statistics and pseudo-labels are used strictly during training; at inference, the router predicts $s_{t,p}$ directly from shallow video features and instruction embeddings.


    Let $q_g = S_g$ when $y_g = 1$ and $q_g = 1 - S_g$ when $y_g = 0$, and let $\rho = F / G$ denote the target fraction of full-resolution groups.
    The router loss terms in Eq.~(4) of the main paper are defined as
    \begin{align}
        \mathcal{L}_{\text{focal}} &= -\frac{1}{G} \sum_{g=1}^{G} \alpha_{y_g} (1 - q_g)^{\gamma} \log q_g, \label{eq:supp_focal} \\
        \mathcal{L}_{\text{budget}} &= \left| \frac{1}{G} \sum_{g=1}^{G} S_g - \rho \right|, \label{eq:supp_budget} \\
        \mathcal{L}_{\text{entropy}} &= -\frac{1}{G} \sum_{g=1}^{G} \big[ S_g \log S_g + (1 - S_g) \log(1 - S_g) \big], \label{eq:supp_entropy}
    \end{align}
    averaged over the mini-batch with $\gamma = 2$ and $\lambda_b = \lambda_e = 0.1$.
    Class-balance weights follow effective-number weighting $\hat{\alpha}_c = (1 - \beta)/(1 - \beta^{n_c})$ with $\beta = 0.999$, normalized so that $\alpha_0 + \alpha_1 = 1$, where $n_c$ counts pseudo-labels of class $c \in \{0, 1\}$ in the batch.
    Scores are clipped to $[10^{-6}, 1 - 10^{-6}]$ inside logarithms for numerical stability.


\paragraph{Temporal boundary placement and positional indexing.}

Let $h_{t,p}$ denote the router's projected feature for tube $p$ at future frame $t$ prior to rotary positional encoding, computed after spatial merging.
We define the frame-to-frame feature variation as $\delta_{p,t} = 1 - \cos(h_{t,p}, h_{t+1,p})$, whose temporal average $\Delta_p = \frac{1}{T-1}\sum_{t=1}^{T-1}\delta_{p,t}$ determines the tube priority $u_p$ in \mainref{eq:priority}.
Sorting all tubes in descending order of $u_p$, we assign segment counts $K_p$ according to the priority tiers in \suppdraft{\cref{tab:supp_schedules}} to meet the target token budget exactly.
Within a tube assigned $K_p$ segments, let $c_t = \sum_{\tau < t} \delta_{p,\tau}$ denote the cumulative variation up to frame $t$, with normalized midpoint $\bar{c}_t = (c_t + c_{t+1})/(2c_T)$ for each candidate boundary between frames $t$ and $t+1$.
We select $K_p - 1$ ordered segment boundaries $1 \le b_1 < \dots < b_{K_p-1} < T$ that minimize
\begin{equation}
  \sum_{q=1}^{K_p-1} \Big(\bar{c}_{b_q} - \frac{q}{K_p}\Big)^2 ,
  \label{eq:supp_cuts}
\end{equation}
so that each segment spans approximately $1/K_p$ of the tube's total variation.
This ordered minimization is solved exactly via dynamic programming with a $10^{-6}$-weighted tie-breaking term favoring uniform segment lengths when variation costs are nearly equal.
Tubes with zero variation receive equal-length segments, and each segment is replaced by the mean of its constituent tokens.

The frozen video DiT uses 3D rotary positional embeddings factorized across time, height, and width.
Spatially, every retained tube keeps the grid coordinate of the top-left source position in its group, preserving alignment between future tubes and observation tokens.
Temporally, contiguous-t assigns the $k$-th pooled segment of every tube the $k$-th future time index, regardless of which source frames the segment spans.
In contrast, source-t assigns each segment the index of the source frame closest to the segment midpoint in cumulative variation.
As illustrated in \mainref{fig:temporal_positions}, source-t leaves large temporal gaps in tubes with small $K_p$ and produces inconsistent index spacing across tubes.

\paragraph{Velocity distillation and adapter merging.}

For each training sample, the full-context teacher and compressed student receive identical inputs and noise draws so that the two branches differ solely by token allocation.
Specifically, both branches share the video noise $\epsilon_v$ at deployment noise scale $\sigma = 80$, the flow timestep $\tau$ sampled from the base trainer's Beta distribution, and the action noise $\epsilon_a \sim \mathcal{N}(0, I)$.
Given a demonstrated action chunk $a$, the noised action input and ground-truth velocity target are defined by flow matching~\cite{lipman2023flow} as
\begin{equation}
    x_\tau = (1 - \tau) a + \tau \epsilon_a, \qquad v_{\text{gt}} = \epsilon_a - a.
    \label{eq:supp_flow}
\end{equation}
Evaluating the frozen base decoder on the full context gives $v_{\text{full}}$ (with gradients disabled), and evaluating the LoRA-adapted decoder~\cite{hu2022lora} on the compressed context gives $v$ at the identical $(x_\tau, \tau)$ and robot state:
\begin{equation}
    \mathcal{L}_{\text{task}} = \|v - v_{\text{full}}\|_2^2 + \lambda_{\text{GT}} \|v - v_{\text{gt}}\|_2^2, \qquad \lambda_{\text{GT}} = 0.02,
    \label{eq:supp_task}
\end{equation}
as in \mainref{eq:task_loss} of the main paper.
Sharing $(\epsilon_v, \epsilon_a, \tau)$ prevents independent noise draws from confounding distillation between full and compressed contexts.
At deployment, each LoRA-adapted projection matrix $W$ is folded into $W + \frac{\alpha}{r} B A$ ($r = 16, \alpha = 8$) and the low-rank branch is removed, incurring zero additional FLOPs or latency.
\Cref{alg:supp_train,alg:supp_infer} summarize training and single-pass inference.

\begin{algorithm}[t]
  \caption{Training \method\ on mimic-video (one suite).}
  \label{alg:supp_train}
  \footnotesize
  \begin{algorithmic}[1]
    \Require Frozen video DiT $V$ and decoder $D$;
    demonstrations; training and deployment
    budget schedules (\suppdraft{\cref{tab:supp_schedules}})

    \State Initialize router $R_\theta$,
    temporary decoder LoRA $\phi$, and saliency
    EMA state $m_g$

    \For{each Stage-1 training step}
      \Comment{Joint adaptation}

      \State Sample a batch of instructions,
      observations, actions $a$, and robot states;
      draw $\epsilon_v,\tau,\epsilon_a$

      \State $Z \gets
      V_{1:2}(\text{observation},\sigma\epsilon_v)$

      \State $s \gets
      R_\theta(Z_{\mathrm{fut}},\text{instruction})$;
      compute $S_g$ by
      \mainref{eq:group_score}

      \State Apply the Stage-1 spatial and temporal
      allocation; gate tubes by $\gamma_g$
      (\suppdraft{\cref{eq:supp_ste}})

      \State $C \gets V_{3:20}(\text{allocated }Z)$

      \State $C_{\mathrm{full}}
      \gets V_{3:20}(Z)$ without gradient

      \State $v \gets
      D_\phi(x_\tau,\tau,\text{state},C)$

      \State $v_{\mathrm{full}}\gets
      D(x_\tau,\tau,\text{state},C_{\mathrm{full}})$

      \State Compute per-sample
      $\mathcal{L}_{\mathrm{task}}^{(i)}$
      by \suppdraft{\cref{eq:supp_task}}

      \State $r_g^{(i)} \gets
      \max(0,
      -\partial\mathcal{L}_{\mathrm{task}}^{(i)}
      /\partial S_g^{(i)})$

      \State $\bar r_g \gets
      \operatorname{mean}_i r_g^{(i)}$

      \State $m_g \gets
      \mu m_g+(1-\mu)\bar r_g$
      \Comment{EMA update}

      \State $\tilde r_g^{(i)}
      \gets \mu m_g+(1-\mu)r_g^{(i)}$

      \State $y_g^{(i)}
      \gets \mathbb{I}
      [g\in\operatorname{TopF}(\tilde r^{(i)})]$

      \State Detach pseudo-labels;
      compute $\mathcal{L}_{\mathrm{router}}$
      by \mainref{eq:router_loss}

      \State Update $\theta,\phi$ using
      $\nabla(\mathcal{L}_{\mathrm{task}}
      +\mathcal{L}_{\mathrm{router}})$

    \EndFor

    \State Freeze the learned router $R_\theta$

    \For{each target token budget $b$}
      \Comment{Stage 2}

      \State Initialize a fresh rank-16
      decoder LoRA $\phi_b$

      \For{each Stage-2 training step}

        \State Sample demonstrations and
        flow-matching noise

        \State Compute early features $Z$
        and input-conditioned router scores

        \State Allocate future tokens using
        the deployed schedule for budget $b$

        \State Compute compressed context
        $C_b$ and full-context teacher
        features $C_{\mathrm{full}}$

        \State Compute student velocity
        $v_b$ and teacher velocity
        $v_{\mathrm{full}}$

        \State Compute $\mathcal{L}_{\mathrm{task}}$
        by \suppdraft{\cref{eq:supp_task}}

        \State Update only $\phi_b$
        using $\nabla_{\phi_b}
        \mathcal{L}_{\mathrm{task}}$

      \EndFor
    \EndFor

    \State \Return $R_\theta$ and
    budget-specific adapters $\{\phi_b\}$

  \end{algorithmic}
\end{algorithm}

\paragraph{Real-robot kitchen tasks.}
Real-world experiments use a 7-DoF Franka Emika Panda arm with a Robotiq 2F-85 gripper in a tabletop kitchen observed by a side-view RGB camera whose $1280{\times}720$ frames are resized to $480{\times}640$.
At a 5Hz cadence, each policy query takes five frames from $t-0.8$s to $t$s alongside the current end-effector state.
The policy predicts 15 relative pose increments in the end-effector frame at 0.2s intervals for a Cartesian impedance controller, executes the first five steps, and replans.
\Cref{tab:supp_robot_tasks} summarizes the six tasks and success criteria across 15 trials per task and method.
All policies in \mainref{tab:real_robot} share the frozen Bridge video backbone and start from task-specific full-context action decoders fine-tuned for 5,000 steps on task demonstrations.
Router and adapter training use the corresponding demonstration splits, normalization statistics, and instruction embeddings.
Stage 1 jointly trains the router and a temporary LoRA adapter for 1,500 steps, and Stage 2 trains a fresh budget-specific LoRA adapter for 1,500 steps with the router frozen.
Both stages use AdamW at batch size 1 with 8 gradient-accumulation steps, 100 warm-up steps, and cosine decay to 5\%, with peak learning rates of $10^{-4}$ for the router and $4\times10^{-5}$ for the LoRA adapter of rank 16 and $\alpha=8$.
At deployment, \method retains the 30\% future-token budget with $F=100$ full-resolution groups and $K=5/8/10$ segments across priority tiers of 120, 180, and 300 tubes, giving 5,040 future tokens and 7,440 total tokens.

\subsection{Allocation schedules and hyperparameters}
\label{app:supp_schedules}

\paragraph{Token budgets and tier schedules.}
\Cref{tab:supp_schedules} summarizes the token budgets and allocation schedules across all backbones and benchmarks.
On mimic-video for LIBERO, all 2,400 observation tokens remain unpooled and each budget specifies the retained future tokens after video block 2.
Keeping $F=100$ of the $G=300$ spatial $2{\times}2$ groups per frame at full resolution produces $P=600$ spatial tubes across the 14 future frames.

\paragraph{Statistical protocol.}
Each configuration uses one training seed and is evaluated with fixed weights across three evaluation seeds that govern stochastic policy execution.
All comparisons pair episodes by benchmark, task, initial-state index, and evaluation seed against the corresponding reference run.
For evaluation seed $s \in \{1, 2, 3\}$ with $N_s$ episodes and binary outcomes $y_{s,i} \in \{0, 1\}$, let $\text{SR}_s = 100 N_s^{-1}\sum_{i=1}^{N_s} y_{s,i}$ denote the seed success rate.
We report the arithmetic mean $\text{SR} = \frac{1}{3}\sum_{s=1}^{3} \text{SR}_s$, which equals the pooled success rate across all $3N_s$ episodes under equal per-seed episode counts.
Point differences $\Delta = \text{SR}_{\text{variant}} - \text{SR}_{\text{reference}}$ are computed from unrounded rates, matching the mean paired outcome difference across all three seeds, while per-task tables sum successful episodes across seeds.

\subsection{Baseline adaptation protocols}
\label{app:supp_baselines}

\ji{
    As external token-reduction baselines were originally designed for observation pruning in VLAs or multi-step diffusion WAMs, we adapt their selection rules to single-pass future-conditioned WAMs under matched Stage-2 LoRA training (\cref{tab:hyperparams}).
    On mimic-video, all baselines retain the 2,400 observation tokens, apply selection at video block 2, and preserve native source coordinates without feature rescaling.
    VLA-Pruner~\cite{liu2025vlapruner}, ADP~\cite{pei2026adp}, and CF-Prune~\cite{kim2026cfprune} score the 1,200 spatial positions of the final observed frame, retain 120 / 240 / 360 positions, and broadcast this spatial mask across all 14 future frames to yield 1,680 / 3,360 / 5,040 future tokens.
    Semantic text-relevance scores use mean raw scaled query-key logits across instruction tokens and heads (since video DiT cross-attention uses text keys only, making softmax sums over keys constant), while action attention averages across all action queries (excluding the proprioceptive query) and all 10 flow steps in FP32.
}


\paragraph{FastV-style.}
\ji{
    Following FastV~\cite{chen2024fastv}, future tokens are ranked by received visual self-attention at video block 2 (averaged across attention heads and visual queries), retaining the top tokens up to the target budget at their native coordinates.
}



\paragraph{VLA-Pruner.}

\ji{
    Following VLA-Pruner~\cite{liu2025vlapruner}, we take the union of the top-$k$ semantic positions and top-$k$ historical action-attention positions, then prune back to $k$ positions via greedy max-min cosine diversity on block-2 features.
    Historical action attention averages action-to-observation cross-attention over the deeper half of the decoder layers across the preceding 3 queries with exponential decay 0.8.
    To initialize this history without cross-episode leakage, the first 3 queries of every episode run at full context, raising measured mean token counts to 5,535 / 7,240 / 8,788 (marked with $^*$ in Tab.~1 of the main paper).
}



\paragraph{ADP.}
\ji{
    Following ADP~\cite{pei2026adp}, top-$k$ semantic token pruning is gated by end-effector displacement relative to the two preceding control steps: displacements below the prior two-step minimum trigger a full-context fallback, and at least one full-context query is forced after every three consecutive pruned queries.
    These fallbacks yield measured mean contexts of 12,101 / 13,059 / 13,881 tokens per query.
}


\paragraph{CF-Prune.}

\ji{
    CF-Prune~\cite{kim2026cfprune} extracts instruction and action attention from an initial denoising step to prune subsequent steps.
    Under single-step WAM inference, no prior denoising step exists; each query therefore runs an unadapted full-context probe pass (through video block 20 and the base decoder) to compute smoothed 50/50 complementary instruction-action scores (selecting low-entropy layers on the first episode query without multi-step phase gating), followed by the compressed LoRA-adapted pass.
    Charging both passes causes total FLOPs and latency to exceed single-pass Full-context inference (Tab.~1 of the main paper).
}


\paragraph{DiT4DiT.}
\ji{
    All four baselines follow the identical selection rules on DiT4DiT using observed/future token quotas of 392/197, 344/98, and 293/98 at the 589-, 442-, and 391-token budgets (thus pruning observation tokens as well at the two smaller budgets), each paired with a dedicated Stage-2 decoder LoRA.
}
