\subsection{Architecture and training}
\label{app:supp_formulation}

\paragraph{Router architecture and gradient saliency.}
    Both mimic-video~\cite{pai2025mimicvideo} and DiT4DiT~\cite{ma2026dit4dit} share the identical router architecture, parameter count, and placement after video block 2.
    At block 2, the router receives 2048-d future tokens and the 1024-d T5 instruction embeddings that condition the video backbone.
    A linear layer projects each future token from 2048-d to 1024-d, followed by rotary positional encoding.
    A single 8-head cross-attention layer lets every future token attend to the instruction tokens with padding masked.
    The cross-attention output is added residually to the projected token, and a two-layer MLP (1024-128-1 with GELU activation) followed by a sigmoid outputs $s_{t,p} \in [0, 1]$.
    In total, the router contains 6.4M trainable parameters (2.1M linear projection, 4.2M cross-attention, and 0.13M MLP), compared with 2B parameters in the frozen mimic-video DiT.
    Counting two operations per multiply-accumulate, scoring all 16,800 future tokens on mimic-video requires 0.18 TFLOPs, corresponding to 0.2\% of a full-context query (98.0 TFLOPs) and 0.4\% of a 20\%-budget query (42.7 TFLOPs).

% \suppdraft{On DiT4DiT, the future-token and instruction inputs are 2,048- and 1,024-dimensional, respectively.
% The router uses 1,024-dimensional cross-attention with eight heads and an MLP with widths 1,024--128--1, for 6,427,905 trainable parameters.
% The input dimensions, parameter count and insertion point after the second video transformer block are shared by both configurations.}
    Selecting the top-$F$ spatial groups at full resolution is a discrete operation whose piecewise-constant ranking yields zero gradient with respect to $S_g$.
    To enable gradient supervision without altering forward activations, every tube constructed from group $g$ (four tubes if kept at full resolution, or one merged tube otherwise) is scaled by a multiplicative straight-through estimator (STE)~\cite{bengio2013estimating}:
    \begin{equation}
        \gamma_g = 1 + S_g - \operatorname{sg}(S_g),
        \label{eq:supp_ste}
    \end{equation}
    where $\operatorname{sg}(\cdot)$ denotes the stop-gradient operator.
    In the forward pass, $\gamma_g = 1$, ensuring identical computation between training and deployment; in the backward pass, $\partial \gamma_g / \partial S_g = 1$.
    Writing $\tilde{z}_i = \gamma_{g(i)} z_i$ for each token $i$ belonging to group $g(i)$, the chain rule yields
    \begin{equation}
        \frac{\partial \mathcal{L}_{\text{task}}}{\partial S_g} = \sum_{i : g(i) = g} \left\langle \frac{\partial \mathcal{L}_{\text{task}}}{\partial \tilde{z}_i},\, z_i \right\rangle,
        \label{eq:supp_chain}
    \end{equation}
    which measures the first-order sensitivity of the task loss to scaling up group $g$'s representation.
    \Mainref{eq:saliency} retains the non-negative descent component, $r_g = \max(0, -\partial \mathcal{L}_{\text{task}} / \partial S_g)$, assigning a high saliency when emphasizing group $g$ reduces $\mathcal{L}_{\text{task}}$.
    Through \cref{eq:supp_ste}, the router receives both direct task gradients $\partial \mathcal{L}_{\text{task}} / \partial S_g$ and stabilized pseudo-label supervision described below, without requiring a full-context probe at test time.


\paragraph{Router objective and target smoothing.}
    For each sample $i$ at training step $n$, we compute the per-sample gradient saliency:
    \begin{equation}
        r_g^{(i,n)} = \max\!\left(0,\, -\frac{\partial \mathcal{L}_{\text{task}}^{(i)}}{\partial S_g^{(i)}}\right).
        \label{eq:supp_saliency}
    \end{equation}
    To reduce gradient variance across stochastic flow-matching steps, we track an exponential moving average (EMA) of the batch-mean saliency $\bar{r}_g^{(n)}$ with momentum $\mu = 0.9$:
    \begin{equation}
        m_g^{(n)} = \mu m_g^{(n-1)} + (1 - \mu)\bar{r}_g^{(n)}.
        \label{eq:supp_ema}
    \end{equation}
    Each sample's smoothed saliency blends this running group statistic with its instantaneous sample gradient:
    \begin{equation}
        \tilde{r}_g^{(i,n)} = \mu m_g^{(n)} + (1 - \mu) r_g^{(i,n)},
        \label{eq:supp_smooth}
    \end{equation}
    from which we construct per-sample binary pseudo-labels by marking the top-$F$ groups:
    \begin{equation}
        y_g^{(i)} = \mathbb{I}\!\big[g \in \operatorname{Top-}F\big(\tilde{r}^{(i,n)}\big)\big].
        \label{eq:supp_pseudolabel}
    \end{equation}
    If a sample yields zero positive saliency across all groups, we substitute its detached current scores $S_g^{(i)}$ prior to \cref{eq:supp_smooth} to avoid degenerate all-zero targets.
    Both the EMA statistics and pseudo-labels are used strictly during training; at inference, the router predicts $s_{t,p}$ directly from shallow video features and instruction embeddings.


    Let $q_g = S_g$ when $y_g = 1$ and $q_g = 1 - S_g$ when $y_g = 0$, and let $\rho = F / G$ denote the target fraction of full-resolution groups.
    The router loss terms in \mainref{eq:router_loss}, including focal classification~\cite{lin2017focal}, are defined as
    \begin{align}
        \mathcal{L}_{\text{focal}} &= -\frac{1}{G} \sum_{g=1}^{G} \alpha_{y_g} (1 - q_g)^{\gamma} \log q_g, \label{eq:supp_focal} \\
        \mathcal{L}_{\text{budget}} &= \left| \frac{1}{G} \sum_{g=1}^{G} S_g - \rho \right|, \label{eq:supp_budget} \\
        \mathcal{L}_{\text{entropy}} &= -\frac{1}{G} \sum_{g=1}^{G} \big[ S_g \log S_g + (1 - S_g) \log(1 - S_g) \big], \label{eq:supp_entropy}
    \end{align}
    averaged over the mini-batch with $\gamma = 2$ and $\lambda_b = \lambda_e = 0.1$.
    Class-balance weights follow effective-number weighting $\hat{\alpha}_c = (1 - \beta)/(1 - \beta^{n_c})$ with $\beta = 0.999$, normalized so that $\alpha_0 + \alpha_1 = 1$, where $n_c$ counts pseudo-labels of class $c \in \{0, 1\}$ in the batch.
    Scores are clipped to $[10^{-6}, 1 - 10^{-6}]$ inside logarithms for numerical stability.


\paragraph{Temporal boundary placement and positional indexing.}

Let $h_{t,p}$ denote the router's projected feature for tube $p$ at future frame $t$ prior to rotary positional encoding, computed after spatial merging.
We define the frame-to-frame feature variation as $\delta_{p,t} = 1 - \cos(h_{t,p}, h_{t+1,p})$, whose temporal average $\Delta_p = \frac{1}{T-1}\sum_{t=1}^{T-1}\delta_{p,t}$ determines the tube priority $u_p$ in \mainref{eq:priority}.
Sorting all tubes in descending order of $u_p$, we assign segment counts $K_p$ according to the priority tiers in \cref{tab:supp_schedules} to meet the target token budget exactly.
Within a tube assigned $K_p$ segments, let $c_t = \sum_{\tau < t} \delta_{p,\tau}$ denote the cumulative variation up to frame $t$, with normalized midpoint $\bar{c}_t = (c_t + c_{t+1})/(2c_T)$ for each candidate boundary between frames $t$ and $t+1$.
We select $K_p - 1$ ordered segment boundaries $1 \le b_1 < \dots < b_{K_p-1} < T$ that minimize
\begin{equation}
  \sum_{q=1}^{K_p-1} \Big(\bar{c}_{b_q} - \frac{q}{K_p}\Big)^2 ,
  \label{eq:supp_cuts}
\end{equation}
so that each segment spans approximately $1/K_p$ of the tube's total variation.
This ordered minimization is solved exactly via dynamic programming with a $10^{-6}$-weighted tie-breaking term favoring uniform segment lengths when variation costs are nearly equal.
Tubes with zero variation receive equal-length segments, and each segment is replaced by the mean of its constituent tokens.

The frozen video DiT uses 3D rotary positional embeddings factorized across time, height, and width.
Spatially, every retained tube keeps the grid coordinate of the top-left source position in its group, preserving alignment between future tubes and observation tokens.
Temporally, contiguous-t assigns the $k$-th pooled segment of every tube the $k$-th future time index, regardless of which source frames the segment spans.
In contrast, source-t assigns each segment the index of the source frame closest to the segment midpoint in cumulative variation.
As illustrated in \mainref{fig:temporal_positions}, source-t leaves large temporal gaps in tubes with small $K_p$ and produces inconsistent index spacing across tubes.

\paragraph{Velocity distillation and adapter merging.}

For each training sample, the full-context teacher and compressed student receive identical inputs and noise draws so that the two branches differ solely by token allocation.
Specifically, both branches share the video noise $\epsilon_v$ at deployment noise scale $\sigma = 80$, the flow timestep $\tau$ sampled from the base trainer's Beta distribution, and the action noise $\epsilon_a \sim \mathcal{N}(0, I)$.
Given a demonstrated action chunk $a$, the noised action input and ground-truth velocity target are defined by flow matching~\cite{lipman2023flow} as
\begin{equation}
    x_\tau = (1 - \tau) a + \tau \epsilon_a, \qquad v_{\text{gt}} = \epsilon_a - a.
    \label{eq:supp_flow}
\end{equation}
Evaluating the frozen base decoder on the full context gives $v_{\text{full}}$ (with gradients disabled), and evaluating the LoRA-adapted decoder~\cite{hu2022lora} on the compressed context gives $v$ at the identical $(x_\tau, \tau)$ and robot state:
\begin{equation}
    \mathcal{L}_{\text{task}} = \|v - v_{\text{full}}\|_2^2 + \lambda_{\text{GT}} \|v - v_{\text{gt}}\|_2^2, \qquad \lambda_{\text{GT}} = 0.02,
    \label{eq:supp_task}
\end{equation}
as in \mainref{eq:task_loss}.
Sharing $(\epsilon_v, \epsilon_a, \tau)$ prevents independent noise draws from confounding distillation between full and compressed contexts.
At deployment, each LoRA-adapted projection matrix $W$ is folded into $W + \frac{\alpha}{r} B A$ ($r = 16, \alpha = 8$) and the low-rank branch is removed, incurring zero additional FLOPs or latency.
\Cref{alg:supp_train,alg:supp_infer} summarize training and single-pass inference.

\subsection{Benchmarks and evaluation protocols}
\label{app:supp_benchmarks}

\paragraph{LIBERO.}
LIBERO-Spatial, LIBERO-Object, and LIBERO-Goal~\cite{liu2023libero} each contain 10 tabletop manipulation tasks in MuJoCo 3.3.4.
We evaluate each task over 50 fixed initial states across three evaluation seeds and report the mean success rate.
Shared initial states within each seed enable paired comparisons across methods.
For mimic-video~\cite{pai2025mimicvideo}, we use the released suite-specific checkpoints with the robot state and five RGB frames, which correspond to two latent observation frames.
Each policy query runs one video denoising step and executes five actions per chunk before replanning.
We exclude LIBERO-Long because our reproduction lacks a corresponding checkpoint and evaluation configuration.
Main evaluations use NVIDIA H100 GPUs, while the ablations in \Cref{tab:supp_depth,tab:supp_objectives,tab:supp_split,tab:supp_temporal} use A100 or H100 GPUs on matched hardware per comparison.


\paragraph{SIMPLER-Bridge.}
    We evaluate mimic-video on the four WidowX manipulation tasks in SIMPLER-Bridge~\cite{li2024simpler}: \texttt{put carrot on plate}, \texttt{put spoon on towel}, \texttt{stack green block on yellow block}, and \texttt{put eggplant in basket}.
    Each task is evaluated over 24 episodes across three evaluation seeds from shared initial states.
    We use the released Bridge checkpoint with both the video backbone and the action decoder frozen.
    Following the LIBERO horizon, each policy query conditions on five RGB frames and the robot state and executes five actions per chunk.

\paragraph{RoboCasa-GR1.}
    RoboCasa-GR1~\cite{nasiriany2024robocasa} consists of 24 tabletop manipulation tasks for the GR1 humanoid, as listed in \Cref{tab:supp_pertask_gr1}.
    Six tasks store an object in an articulated container and close the door or drawer, while 18 tasks transfer a novel object between tabletop receptacles.
    We evaluate 50 episodes per task across three evaluation seeds from shared initial states.
    DiT4DiT~\cite{ma2026dit4dit} uses the released GR1 checkpoint conditioned on the robot state and a $224\times 224$ egocentric RGB image with aspect-ratio padding.
    The video backbone processes one observed latent frame and two future latent frames of $14\times 14$ tokens each, totaling 588 tokens per query.

\paragraph{Real-robot kitchen tasks.}
    Real-world experiments use a 7-DoF Franka Emika Panda arm, a Robotiq 2F-85 gripper, and a side-view RGB camera in a tabletop kitchen environment.
    Camera frames are captured at $1280\times 720$ resolution and resized to $480\times 640$ at 5\,Hz.
    At each policy query, the model receives the current end-effector state and five RGB frames spanning the preceding 0.8\,s.
    The policy predicts a 15-step chunk of relative end-effector poses at 0.2\,s intervals for a Cartesian impedance controller.
    Following a receding-horizon setup, the robot executes the first five actions before replanning.
    All methods in \mainref{tab:real_robot} share the frozen Bridge video backbone and start from task-specific full-context action decoders fine-tuned for 5,000 steps.
    Router and adapter training uses the corresponding demonstration splits, normalization statistics, and instruction embeddings.
    Stage 1 jointly trains the router and a temporary LoRA adapter for 1,500 steps, and Stage 2 trains a fresh budget-specific LoRA adapter for 1,500 steps with the router frozen.
    Both stages use AdamW with batch size 1, 8 gradient accumulation steps, 100 warmup steps, and cosine decay to 5\%.
    Peak learning rates are $10^{-4}$ for the router and $4\times 10^{-5}$ for the rank-16 LoRA adapter with $\alpha=8$.
    At inference, \method uses the 30\% future-token schedule in \Cref{tab:supp_schedules}, retaining $F=100$ full-resolution groups and 5, 8, and 10 segments across tiers of 120, 180, and 300 tubes for 7,440 total tokens.

\subsection{Allocation schedules and hyperparameters}
\label{app:supp_schedules}

\paragraph{Token budgets and tier schedules.}
    \Cref{tab:supp_schedules} details the token budgets and allocation schedules across all backbones and benchmarks.
    On mimic-video for LIBERO, all 2,400 observation tokens remain uncompressed, and each budget specifies the future tokens retained after video block 2.
    Each future frame of $30\times 40$ tokens forms $G=300$ spatial $2\times 2$ groups.
    Retaining $F=100$ full-resolution groups and merging the remaining 200 groups produces $P=600$ spatial tubes across the 14 future frames.
    Tubes are ranked into priority tiers of 120, 180, and 300 tubes and assigned 1/2/4, 3/5/7, and 5/8/10 temporal segments, giving 1,680, 3,360, and 5,040 future tokens at the 10\%, 20\%, and 30\% budgets.
    On SIMPLER-Bridge, setting $F=100$ limits the maximum context to 10,800 tokens across the 14 future frames.
    We therefore set $F=200$ to form $P=900$ tubes while preserving the 20\%/30\%/50\% tier proportions of 180, 270, and 450 tubes.
    On DiT4DiT for LIBERO, the backbone predicts a single future latent frame of $G=98$ spatial groups, leaving $K=1$ temporal segment per tube.
    The 75\% budget keeps all 392 observation tokens and $F=33$ future groups.
    At the 55\% and 50\% budgets, all future groups are merged into 98 tokens, and $2\times 2$ spatial merging is also applied to the observed frame with $F=82$ and $F=65$.
    On DiT4DiT for RoboCasa-GR1, the two future latent frames allow 1 or 2 segments per tube.
    The 539 and 490 token budgets apply temporal pooling alone across all $P=196$ tubes, whereas the 466 token budget combines spatial merging at $F=41$ with temporal pooling across 74 tubes.

\paragraph{Optimization hyperparameters.}
    Training proceeds in two stages, with mimic-video hyperparameters summarized in \Cref{tab:supp_hparams}.
    In Stage 1, the router and a temporary decoder LoRA adapter are jointly trained under $\mathcal{L}_{\mathrm{task}} + \mathcal{L}_{\mathrm{router}}$.
    On mimic-video for LIBERO, Stage 1 combines $2\times 2$ spatial merging at $F=100$ with uniform temporal pooling into 12, 10, or 8 segments on LIBERO-Spatial and LIBERO-Goal, and 8, 6, or 4 segments on LIBERO-Object.
    In Stage 2, we freeze the router and train a fresh rank-16 LoRA adapter with $\alpha=8$ and 3.9M parameters on the decoder cross-attention layers under each deployed schedule in \Cref{tab:supp_schedules}.
    Both stages minimize $\mathcal{L}_{\mathrm{task}}$ in \Cref{eq:supp_task} with $\lambda_{\mathrm{GT}}=0.02$ for 1,500 steps using AdamW with batch size 1, 8 gradient accumulation steps, maximum gradient norm 1.0, 100 warmup steps, and cosine decay to 5\%.
    Peak learning rates are $10^{-4}$ for the router in Stage 1 and $4\times 10^{-5}$ for the LoRA adapter in both stages.
    DiT4DiT follows the same two-stage protocol on LIBERO and RoboCasa-GR1 for 1,500 steps per stage with peak learning rates of $10^{-4}$ and $4\times 10^{-5}$.

\paragraph{Statistical protocol.}
    Each model is trained once and evaluated with fixed weights across three evaluation seeds.
    Within each benchmark, task, and evaluation seed, all methods run from identical initial states to form paired episodes.
    For evaluation seed $s \in \{1, 2, 3\}$ with $N_s$ episodes and binary outcomes $y_{s,i} \in \{0, 1\}$, we define the seed success rate as $\mathrm{SR}_s = \frac{100}{N_s}\sum_{i=1}^{N_s} y_{s,i}$.
    We report the mean success rate $\mathrm{SR} = \frac{1}{3}\sum_{s=1}^{3} \mathrm{SR}_s$, which equals the pooled success rate across all $3N_s$ episodes.
    Differences $\Delta = \mathrm{SR}_{\mathrm{variant}} - \mathrm{SR}_{\mathrm{reference}}$ are computed from unrounded rates, and per-task tables report total successful episodes summed across the three evaluation seeds.

\subsection{Baseline adaptation protocols}
\label{app:supp_baselines}
    Prior token-reduction methods target observation pruning in VLAs or multi-step denoising in diffusion WAMs.
    To evaluate these methods in single-pass future-conditioned WAMs, we adapt each selection rule and train a dedicated Stage-2 decoder LoRA adapter per budget following \Cref{tab:supp_hparams}.
    On mimic-video, all baselines keep the 2,400 observation tokens and select future tokens at video block 2 on native coordinates without feature rescaling.
    VLA-Pruner~\cite{liu2025vlapruner}, ADP~\cite{pei2026adp}, and CF-Prune~\cite{kim2026cfprune} score the 1,200 spatial positions of the final observed frame and retain 120, 240, or 360 positions.
    Applying the selected spatial mask across all 14 future frames yields 1,680, 3,360, or 5,040 future tokens.
    Because video DiT cross-attention normalizes softmax weights over instruction keys, post-softmax weights sum to one at every visual token.
    We therefore compute instruction-relevance scores as the mean pre-softmax query-key logits across instruction tokens and attention heads.
    Action-attention scores average cross-attention weights in FP32 across all action queries and all 10 flow-matching steps, excluding the proprioceptive state token.

\paragraph{FastV-style.}
    Following FastV~\cite{chen2024fastv}, we rank future tokens by the mean self-attention weight received from all visual queries across attention heads at video block 2.
    The top-scoring future tokens up to the target budget are retained at native spatial and temporal coordinates.

\paragraph{VLA-Pruner.}
    Following VLA-Pruner~\cite{liu2025vlapruner}, we take the union of the top-$k$ instruction-relevant positions and the top-$k$ positions ranked by historical action attention.
    This union is reduced to $k$ positions via greedy max-min cosine distance selection on block-2 features.
    Historical action attention averages action-to-observation cross-attention over the upper half of the decoder layers across the preceding 3 queries with an exponential decay of 0.8.
    To initialize this history without cross-episode leakage, the first 3 queries of each episode run at full context, resulting in mean context lengths of 5,535, 7,240, and 8,788 tokens as marked by $^*$ in \mainref{tab:main_results}.


\paragraph{ADP.}
    Following ADP~\cite{pei2026adp}, top-$k$ instruction-based pruning is gated by end-effector displacement relative to the previous two control steps.
    Queries with displacement below the minimum of the preceding two steps revert to full-context inference, and one full-context query is enforced after every three consecutive pruned queries.
    Including these full-context fallback queries yields mean context lengths of 12,101, 13,059, and 13,881 tokens across the three budgets.



\paragraph{CF-Prune.}
    CF-Prune~\cite{kim2026cfprune} extracts instruction and action attention from an initial denoising step to prune tokens in subsequent steps.
    Because single-step WAM inference has no earlier denoising step, each query first runs an unadapted full-context probe through video block 20 and the base decoder without multi-step phase gating.
    On the first query of each episode, CF-Prune selects minimum-entropy attention layers and combines smoothed instruction and action attention maps in equal 50/50 proportions.
    A second forward pass then predicts actions from the pruned context using the dedicated LoRA adapter.
    Executing both forward passes per query increases total FLOPs and latency above single-pass Full-context inference in \mainref{tab:main_results}.

\paragraph{DiT4DiT.}
    We apply the same four selection rules on DiT4DiT using observed/future token quotas of 392/197, 344/98, and 293/98 for the 589, 442, and 391 token budgets.
    At the 442 and 391 token budgets, each baseline prunes both observed and future tokens, and every configuration is paired with a dedicated Stage-2 decoder LoRA adapter.
